# 使用与接线

主控为 ESP32-S3-CAM，实测 16MB Flash（固件按 8MB 配置）、8MB OPI PSRAM，最近串口 COM6。副板为 AI Thinker 兼容经典 ESP32-CAM，4MB Flash、4MB PSRAM，最近串口 COM15。串口号可能变化。

## 外设接线（全部接主控）

| 外设端子 | 主控 GPIO / 电源连接 |
| --- | --- |
| 舵机 1 信号 | GPIO1 |
| 舵机 2 信号 | GPIO2 |
| 舵机 3 信号 | GPIO21 |
| 三个舵机电源正极 | 独立 5–6V 电源正极，按舵机额定电压供电 |
| 三个舵机地线 | 外部电源负极，与主控 GND 共地 |
| AHT20 VIN / GND | 3V3 / GND |
| AHT20 SDA / SCL | GPIO14 / GPIO47 |
| D4184 1 PWM（窝内灯） | GPIO41 |
| D4184 2 PWM（氛围灯） | GPIO42 |
| 两个 D4184 信号 GND | 主控 GND，与灯带电源负极共地 |

D4184 电源正端接灯带电源正极，电源负端接负极；灯带正极接电源正极，灯带负极接对应模块 LOAD，以实物标识为准。电压须匹配灯带。GPIO 只提供信号，不给灯带或舵机供电。外部 6V 不接开发板 5V/USB；改线前断电。

## 功能

- 下料按钮对应三路舵机，任意时刻仅运行一个。默认每圈 1.2 秒，估算 5 圈共 6 秒；没有编码器，不保证真实圈数。可逐路调整每圈用时。
- 舵机 50Hz PWM，运行 2000µs、停止 1500µs，停止点需现场校准。独立任务到时停止，不依赖网页保持打开。
- 灯带高电平打开、低电平关闭。上电默认关灯，舵机输出停止指令。灯带状态是 GPIO 回读，不是发光检测。
- AHT20 地址 0x38，约 2.1 秒采样一次，网页每 3 秒刷新，数据无效或过期显示暂无数据。
- 摄像头 320×240、JPEG 质量参数 16，目标 25fps，实际帧率随网络及光照变化。切换时停止旧连接；副板 IP 变化后由主控自动发现，二号预览及保存照片旋转 180°。
- 右上角 Wi-Fi 只支持两台一起设置网络，见 [Wi-Fi设置](Wi-Fi设置.md)。

| SDA / SCL | 4 / 5 | 26 / 27 |
