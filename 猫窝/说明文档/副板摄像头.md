# 副板摄像头与维护

当前版本 `cat-camera-remote-pair-2`，经典 ESP32-CAM、OV2640、4MB Flash 和 4MB PSRAM。副板根路径返回状态，主界面由一号主控提供；摄像头 IP 由主控自动发现，无手填入口。

## 运行与供电

正常使用外部稳压 5V 接 5V/GND。此前下载底座连接时多次出现联网或出图异常，取下底座、外部供电后恢复；具体电气原因未确定。拔插底座、摄像头排线及改线前断电。进入下载模式须断开全部其他供电和接线，避免 USB 拔掉后板子仍带电。

串口最近为 COM15，波特率 115200；`status` 和 `network` 查询状态。完整烧录步骤见 [编译与烧录](编译与烧录.md)。运行时不按 IO0，去掉 IO0-GND 下载跳线。

## 固件行为

- 无 OTA，使用默认 huge_app 单应用分区，更新通过 USB 写入四段固件。
- 摄像头 20MHz XCLK、320×240、JPEG 质量参数 16，有 PSRAM 时双缓冲。
- 保留异步拍照、单路视频限制、Wi-Fi 搜索与设置、设备发现和状态诊断。
- 有限 HTTP 响应成功后交给服务器管理连接；异常连接关闭，保留 LRU 清理。
- 网页视频连接失败时回退抓拍，旧帧标注“画面未更新”；二号旋转由主控网页完成。

## 出图检查与当前状态

访问 `/api/camera/status` 核对 ready/error，再从 `/api/camera/capture` 获取并解码 JPEG；仅 ready=true 不代表能看到画面。切换二号摄像头观察连续更新，并在完全断电后复测。只读硬件检查脚本见 `Web源码/tests/camera-device.cjs`，需设置 CAMERA_DEVICE_URL 为实际地址。

最近一次恢复至 Allensun 后，副板为 192.168.0.4，与主控互相发现；连续三次 320×240 JPEG 解码成功，耗时约 0.08–0.16 秒。此前 Allensun 连续 30 次检查通过，2313 仍出现丢包。短测不代表长期稳定性，供电及发热也未完成测量验证。
