## 当前版本与入口

主控 `cat-home-pair-2`，副板 `cat-camera-remote-pair-2`。二号预览及保存照片旋转 180°；两摄像头切换播放，二号地址自动发现。Wi-Fi 页面只保留两台一起连接。

最近一次实测两板均连接 **Allensun**，主界面为 http://192.168.0.3/，副板为 192.168.0.4；这些是 DHCP 当时分配的地址，不是固定地址。手机或电脑必须连接同一网络。也可尝试 http://cat-home.local/，是否可用取决于网络和客户端的 mDNS 支持。
